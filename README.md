# IRON FRONT · WORLD AT WAR

Первый вертикальный срез, версия 0.1. Это ещё не готовый MVP и не production-релиз.

## Реализованный сценарий

Telegram initData → сохранённый аккаунт → выбор одного из 6 командиров → электростанция → карьер → казармы → стрелковое отделение → тактический PvE-бой → награда и уникальный модуль → экипировка → повторный вход.

- FastAPI + SQLAlchemy + Alembic, PostgreSQL — источник истины.
- Сессии с хешированными токенами; Telegram HMAC и срок initData 5 минут.
- Все игровые изменения сериализуются блокировкой строки игрока.
- Ключ идемпотентности привязан к игроку и отпечатку команды. Одинаковая команда возвращает исходный результат; иной payload с тем же ключом отклоняется.
- Ресурсный журнал, неотрицательные остатки, уникальность клетки базы, единичная награда за учебную миссию.
- 61 гекс базы; штаб и 4 строящихся типа зданий; 5 ресурсов; минутное производство; максимум 24 часа офлайн, склад 5 000 каждого ресурса.
- Сохранённая очередь обучения; один тип войск в срезе.
- Поле 9×9: движение, атака, защита, укрытия, одновременный урон, seed, версия баланса и журнал раундов. После поражения отряд сохраняет минимум 50 HP. Повторной награды после победы нет.
- Шесть командиров с ограниченными стартовыми эффектами, XP за первую победу; один уникальный тип предмета с историей происхождения и серверным бонусом +3% к урону.
- Общая карта 128×128, 4 биома, ограниченная выдача чанков, скрытая местность вне начального обзора. Походов и захвата пока нет.
- React + TypeScript + PixiJS, сенсорное перемещение/масштабирование, серверные таймеры, WebSocket со снимком при переподключении.
- Процесс бота: `/start`, `/play` и кнопка открытия Mini App. Нужны реальные BOT_TOKEN и APP_URL.

## Локальный запуск

Требуются Docker и Docker Compose. Создайте `.env` из `.env.example`. Укажите токен **отдельного тестового бота** и HTTPS URL своего приложения. Токен не передавайте в frontend, GitHub или архив.

```sh
cp .env.example .env
docker compose up --build
# после настройки HTTPS APP_URL:
docker compose --profile bot up -d bot
```

API и интерфейс: `http://localhost:8000`. OpenAPI: `/docs`, `/openapi.json`. Полный проверяемый snapshot OpenAPI — `docs/openapi.json`.

Локальный HTTP адрес нельзя открыть из Telegram на телефоне: нужен HTTPS домен/туннель. В production нет тестового входа, фиктивных денег или поддельных API-ответов. Для авторизации всегда нужна подпись Telegram.

## Тесты

```sh
python3.12 -m venv .venv
.venv/bin/pip install -r requirements.lock
docker compose up -d postgres redis
cd server
export APP_ENV=test
export TEST_DATABASE_URL=postgresql+psycopg://iron:iron@localhost:5432/iron
../.venv/bin/python -m pytest -q
```

Интеграционные тесты создают отдельную случайную схему и удаляют **только её**. Всё равно используйте отдельную тестовую БД. Без TEST_DATABASE_URL интеграционные проверки явно пропускаются. CI поднимает отдельные PostgreSQL 16 и Redis, выполняет миграции, проверку схемы, все тесты и сборку клиента.

```sh
cd client
npm ci
npm run build
npx playwright install chromium
# Только тестовая среда с тестовым токеном. Браузерный сценарий занимает около 3–4 минут.
TEST_APP_URL=http://localhost:8000 BOT_TOKEN=TEST_BOT_TOKEN node tests/cycle.mjs
```

В браузерном тесте нет подмены API или мгновенных таймеров: электростанция 30 сек., карьер 45 сек., казармы 60 сек., стрелки 45 сек. Тест сам подписывает данные фиктивного тестового пользователя известным тестовым токеном. Не направлять его в production.

## Что ещё не готово

См. `docs/STATUS.md` и `docs/ARCHITECTURE.md`. Полноценные игровые ассеты и портреты заменены явно обозначенными техническими эмблемами и процедурной геометрией. Нет оплаты, рынка, PvP, альянсов, админ-панели, исследований, перемещения армий по глобальному миру, захвата территорий, комплектов и полного инвентаря из восьми слотов. Вкладка альянса прямо сообщает, что функция недоступна.

Ни FPS на реальном телефоне, ни поведение внутри iOS/Android Telegram пока не подтверждены. Публиковать для игроков до прохождения release gates нельзя.
