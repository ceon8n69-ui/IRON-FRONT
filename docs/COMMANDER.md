# Рост командира · 0.12

Код: `server/app/commander.py`, `server/app/equipment.py`, тесты: `server/tests/test_commander.py`.

## Уровни и навыки

- Уровень считается из опыта: 0, 100, 250, 450, 700, 1000, 1400, 1900, 2500, 3200, 4000, 4900, 5900, 7000, 8200 XP (максимум 15).
- Каждый уровень даёт +1 % урона и +1 % защиты соединению командира и одно очко навыка.
- За очко навыка игрок выбирает один из трёх предложенных: новый навык или следующий ранг уже изученного. Набор предложений зависит только от игрока и числа сделанных выборов: при перезагрузке он не меняется и переиграть его нельзя.
- Всего 12 навыков, до 6 изученных, у каждого 3 ранга:

| Навык | I / II / III | Где работает |
|---|---|---|
| Натиск | урон +5/10/15 % | соединение командира |
| Стойкость | получаемый урон −5/10/15 % | соединение командира |
| Артиллерия | урон стрелков +10/20/30 % | соединение командира |
| Тактика | инициатива +1/2/3 | соединение командира |
| Боевой дух | шанс 8/14/20 % на лишнее действие | соединение командира |
| Удача | шанс 8/14/20 % на удар ×1.5 | соединение командира |
| Логистика | очки хода +2/4/6 | соединение командира |
| Разведка | обзор +1/2/3 | соединение командира |
| Полевая медицина | после боя возвращается 10/20/30 % павших | соединение командира |
| Мародёрство | трофеи с карты, моря и налётов +15/30/45 % | везде |
| Снабжение | производство базы +5/10/15 % | везде |
| Инженерия | стройка и улучшения быстрее на 10/20/30 % | везде |

## Артефакты

Пять слотов: оружие, броня, знак отличия, модуль, снаряжение. В каждом слоте один предмет, новый заменяет старый. 16 артефактов трёх редкостей. С гарнизонов падают по таблице `gar-loot-v2`: у «Роты» и «Батальона» шанс редких и эпических выше. Иконки сгенерированы тем же конвейером (`kind: item`).

## Бой

- Бонусы командира записываются в состояние боя при его начале (`state.perks`), так что баланс боя не меняется на ходу. В бою без командира бонусов нет.
- Прогноз удара (`battle.preview`): для активного стека и каждой вражеской цели показаны урон, сколько бойцов погибнет и ответный удар. Удача в прогноз не входит.
- Быстрый бой (`POST /battles/auto`): сервер доигрывает бой за игрока тем же ИИ, что у NPC, без способностей. Каждый ход сохраняется в реплее с пометкой `auto`.
- Бои, начатые до 0.12, продолжают работать со старым бонусом экипировки.
