- TypeScript typecheck и Vite production build — PASS.

- 1 конкурентный тест намеренно исключён из локального прогона. GitHub Actions запускает его на PostgreSQL 16 вместе со всеми остальными тестами.
- Alembic upgrade, seed, Alembic check — PASS. В мире 16 384 клетки. Схема соответствует моделям.
- npm audit и pip-audit по зафиксированным зависимостям — 0 известных уязвимостей на момент проверки.
- Браузерный полный цикл — PASS на Chromium 134 с мобильным viewport 390×844: настоящие таймеры трёх построек и обучения, перемещение и атаки, победа, награда, экипировка и перезагрузка. Нет ошибок JavaScript и горизонтального переполнения. Проверен также desktop viewport 1280×900. Это эмуляция браузера, не реальный Telegram на телефоне.
