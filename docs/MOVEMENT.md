# Movement points and routes · 0.5

Ход по мировой карте устроен как в «Героях», но без строгих ходов: очки хода восстанавливаются в реальном времени, поэтому играть можно без постоянного онлайна.

## Rules

- У соединения 30 очков хода, у генерала Шторма 34.
- Очки восстанавливаются по +1 каждые 4 минуты, полный запас за 2 часа. Регенерация считается на сервере при обращении и не идёт сверх лимита. Её отсчёт начинается с первой потраченной единицы.
- Цена входа на гекс: равнина 1, лес 2, пустыня 2, холмы 3.
- Приказ можно отдать на любой разведанный гекс. Сервер ищет самый дешёвый путь (Dijkstra), путь проходит только по известной местности.
- Через чужие территории и базы путь не строится. Чужое владение может быть только целью атаки (PVP.md).
- Через гарнизон NPC пройти нельзя. Гарнизон может быть только конечной целью, тогда на прибытии начинается бой.
- Расход топлива — 1 за каждый пройденный гекс. Время в пути — 10 секунд за каждое потраченное очко.
- Соединение идёт по маршруту шаг за шагом. Позиция и разведка обновляются на каждом пройденном гексе, в том числе при офлайн-начислении.
- Если конечный гекс занял другой игрок, соединение останавливается на предыдущем гексе.
- Захват по-прежнему требует, чтобы цель граничила с базой или своей территорией.

## API

- `GET /api/v1/army/route?q&r` — предпросмотр без изменений состояния. Возвращает путь с ценой каждого шага, сумму очков, топливо, время и флаг `affordable`. Если маршрута нет, отвечает 409 с причиной.
- В `POST /api/v1/army/orders` убрано ограничение «только соседний гекс». Сервер сам считает маршрут, списывает очки хода и топливо и сохраняет путь `[[q, r, arrive_at], ...]`.
- В snapshot у соединения появились поля `movement`, `movement_max`, `movement_next_at`, у приказа — поле `path`.

Миграция `d5e2f9a7c1b3` аддитивная: добавляет `armies.movement` (по умолчанию 12, существующие соединения стартуют с полным запасом), `armies.movement_at` и `army_orders.path`. Старые одношаговые приказы без `path` продолжают работать. Версия баланса — `slice-5`.

## Client

- Шкала хода показывает запас и время до следующего очка.
- При выборе гекса на карте рисуется зелёный путь, на каждом шаге подписана накопленная стоимость.
- В карточке гекса выводятся гексы, очки хода, время и топливо, а если идти нельзя — причина.
- Во время похода маркер движется по линии пути от гекса к гексу.

## Несколько соединений

Очки хода считаются для каждого соединения отдельно. Лимит соединений: `EXPEDITIONS.armies_base` + (уровень штаба − 1) // 2, но не больше `armies_cap`. Маршрут `GET /army/route` принимает `army_id`. Без него берётся соединение командира.
