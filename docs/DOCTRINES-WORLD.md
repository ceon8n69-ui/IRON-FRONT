# Доктрины, руины, лагеря наёмников · 0.15

Код: `server/app/doctrines.py` и `server/app/objects.py` (руины и лагеря). Тесты: `server/tests/test_doctrines.py`.

## Доктрины

Дерево развития в духе Polytopia: три ветки по три яруса. В каждом ярусе выбирается **одна доктрина из двух**, вторая закрывается до конца сезона. Следующий ярус открывается, когда изучен предыдущий в той же ветке. Одновременно идёт одно исследование. Инженерия командира ускоряет исследования. С новым сезоном доктрины сбрасываются.

| Ветка | Ярус 1 | Ярус 2 | Ярус 3 |
|---|---|---|---|
| Пехота | Окопы: урон по пехоте −10 % / Штыковой натиск: урон пехоты +10 % | Массовый призыв: пехота дешевле на 20 % / Ветераны: урон +8 %, защита +5 % | Полевые кухни: расход провизии −30 % / Ударные группы: урон пехоты +15 % |
| Техника | Бронелисты: урон по технике −10 % / Форсированные моторы: урон техники +10 % | Конвейер: техника готовится на 30 % быстрее / Тяжёлые калибры: урон орудий +15 % | Экономия топлива: расход топлива −30 % / Бронированный кулак: урон техники +15 % |
| Логистика | Дороги: +2 очка хода / Разведка боем: обзор +1 | Склады: вместимость +25 % / Военные заводы: производство +10 % | Штаб фронта: +1 соединение / Удержание рубежей: лимит территорий +4 |

Стоимость: ярус 1 — 400 металла и 80 электроники, 10 минут; ярус 2 — 900 и 200, 30 минут; ярус 3 — 1800, 400 и 200 топлива, 1 час.

Боевые доктрины действуют в боях **всех** соединений, а не только соединения командира: они попадают в `state.perks` при начале боя.

## Руины

Около 1 % клеток карты. Внутри одна заранее определённая для этого гекса находка, её получает первый пришедший:

- тайник: +400 металла, +100 электроники, +100 топлива;
- архив штаба: +150 опыта командиру;
- артефакт (по таблице с повышенным шансом редкости);
- уцелевшие бойцы: стек линейной пехоты фракции на 6 человек уходит в резерв;
- старые карты: открывается местность на 6 гексов вокруг.

## Лагеря наёмников

Около 1 % клеток. В каждом лагере свой отряд чужой фракции: стрелки, разведка или штурмовики. Соединение, стоящее в лагере, может нанять отряд за 125 % его обычной цены. Отряд встаёт в соединение, если есть место, иначе уходит в резерв. В лагере **один отряд на игровую неделю** (реальные сутки): кто первым нанял, того и отряд.
