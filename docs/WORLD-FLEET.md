# World v2, fleet and unit abilities · 0.9

## World generation (`server/app/worldgen.py`)

- Seeded шумовой генератор (`iron-world-2`). Мир детерминированный: одинаковый на всех серверах и при каждом запуске.
- Карта 128×128. Высота — фрактальный шум плюс 16 «плит» разного размера: материки, средние острова, островки. Влажность — отдельный шум. Пропорции задаются перцентилями высоты: 40% воды, 14% холмов, 6% гор.
- Получается так:
  - океан по краю, внутренние моря и проливы;
  - вода, не связанная с краем карты, становится озером, плюс дюжина озёр в низинах;
  - 40 рек текут вниз по рельефу к воде;
  - пляжи на берегах, около 40 островков в открытом море.
- Биомы: море, озеро, река, пляж, равнина, лес, холмы, горы, пустыня.

## Movement

| Биом | Без флота | С флотом |
|---|---|---|
| Равнина, пляж | 1 | 1 |
| Лес, пустыня | 2 | 2 |
| Холмы | 3 | 3 |
| Река | 3 (брод) | 1 |
| Море, озеро | нельзя | 1 |
| Горы | нельзя | нельзя |

Посадка на корабли и высадка на берег стоят +2 очка хода. Водные гексы нельзя захватить.

## Fleet

- **Верфь** (нужен штаб 2) строит корабли, общие для всех командиров:
  - Десантный катер — верфь 1, способность «Дымовая завеса»;
  - Канонерка — верфь 2, дальность 5, способность «Бортовой залп»;
  - Бронекатер — верфь 3, таран, способность «Таран».
- Любой корабль в соединении позволяет ходить по воде.
- В морском бою сражаются только корабли, на суше — только сухопутные стеки.
- **Пираты** на море в трёх силах: Пиратский дозор, Пиратская флотилия, Пиратская армада. Победа очищает точку для всех игроков (таблица `map_cleared`), даёт ресурсы, опыт и трофей.
- **Обломки** на море — кучи металла, топлива или электроники.

## Unit abilities

- У каждого из 38 типов юнитов есть своя способность (`UNIT_ABILITIES`), раз за бой: команда `skill`, кнопка «◆» на панели боя.
- Внутри одной фракции все пять способностей разные.
- Эффекты:
  - **strike** — усиленная атака;
  - **splash** — урон соседним с целью;
  - **dash** — рывок, после которого стек ещё действует;
  - **suppress** / **suppress_attack** — ослабление цели и без ответного удара;
  - **jam** — цель пропускает ход;
  - **fortify** — оборона;
  - **guard_aura** / **smoke** — защита соседей;
  - **heal** / **heal_aura** — лечение;
  - **mark** — цель получает больше урона;
  - **longshot** — выстрел без ограничения дальности.
- Флаги эффектов действуют до конца раунда. Способность командира (★) работает отдельно, как раньше.

## Raster art pipeline

- **Поле боя** сначала грузит `/art/units/<kind>.png`. Если файла нет, рисует бойца кодом.
- **Формат:** 256×224, RGBA, ноги на 82% высоты, фигура смотрит вправо.
- **Пакет промптов:** `docs/ART-PROMPTS.md`, по одному на каждый файл.
- **Текущие PNG** сгенерированы из кодового арта (`tools/render-units.mjs`). Чтобы заменить бойца, перезапиши файл.
