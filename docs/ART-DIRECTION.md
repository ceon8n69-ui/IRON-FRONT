# Art direction and commander factions · 0.8

## Direction

Направление задано референсами владельца:
- Чиби-дизельпанк: крупные головы, каски-«тазики», противогазы, ранцы с баллонами, экзоброни с дымовыми трубами, четвероногие шагоходы с фарами.
- Яркие изометрические гексы-диорамы: сочная трава, тёмный земляной край, толстый чернильный контур.
- Круглые деревья и ели, кусты с цветами, камни со мхом, пни и грибы.
- Здания с тёплыми крышами.

Изображения из референсов в игру **не скопированы и не нарезаны**: права на них не подтверждены. Весь арт в этом релизе оригинальный, нарисован кодом.

## What shipped

- **`src/Units.ts`** — 22 оригинальных силуэта бойцов и техники, собранных из общих деталей и окрашенных в цвет фракции:
  - пехота: стрелки, разведчики, штурмовики, диверсанты, снайперы, щитоносцы, медики, инженеры;
  - расчёты: пулемётный, мортирный, полевая пушка, разрядная пушка;
  - машины: дроны, автоматоны, бронеавтомобиль, САУ;
  - тяжёлые: три шагохода и три экзоброни.
- **`src/Terrain.ts` и палитра в `Map.tsx`** — яркие гексы с земляным краем и контуром; лиственные и осенние деревья, ели, кусты с цветами, камни, пни, грибы, сухие кусты в пустыне.
- **`src/Buildings.ts`** — тёплые крыши по семействам зданий, светлые стены, контур, земляной край площадки. Полностью перерисованы пока только штаб и общие блоки; у остальных зданий ещё есть старые детали.
- **`public/art/units/<key>.png`** — 35 заранее отрисованных спрайтов для интерфейса: превью отряда при выборе командира и меню найма. Перегенерировать: `TEST_APP_URL=… node tools/render-units.mjs`.
- **Галерея всех отрядов:** `/?gallery`.

**Замена на растровый арт.** Если художник или генератор сделает спрайты, их нужно положить в `public/art/units/` под теми же именами `<key>.png`: интерфейс подхватит их без изменений кода. Подстановка растра на тактическом поле — следующий шаг, сейчас поле рисует код.

- Каждый вариант наследует базовые параметры своей роли (`UNITS`) и меняет их немного, плюс получает не больше одного свойства. Сила вариантов держится в пределах 0.6–1.35 от базовой роли; тест это проверяет.
- Нанимать можно только юнитов своей фракции. Запрос по имени роли (`rifles` и т. д.) превращается в вариант своей фракции.
- Старые отряды базовых типов продолжают работать. NPC используют базовые типы.

## Traits (server)

| Свойство | Эффект |
|---|---|
| Штыковой бой | Ответный удар вплотную без штрафа стрелков |
| Внезапная атака | Цель не наносит ответный удар |
| Натиск | +30% урона, если стек подошёл к цели в этом ходу |
| Щиты | Урон от стрельбы ×0.6 |
| Меткость | Игнорирует укрытия и не теряет точность вплотную |
| Пробой | Игнорирует защиту цели |
| Медики | После хода лечат соседние свои стеки на 15% |
| Саморемонт | После хода стек восстанавливает 10% здоровья |

Версия баланса — `slice-8`, API — `0.8.0`. Миграций нет: тип юнита хранится строкой.
